# Subus v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Нативное приложение строки меню macOS «Subus» для учёта подписок: ближайшие списания, итоги в основной валюте по курсу ЦБ, напоминания за 5/3/1 день до списания и до конца пробного периода.

**Architecture:** Вся логика (модель, расписание, планировщик напоминаний, курсы, хранилище, импорт/экспорт, логотипы, представление) живёт в SPM-пакете `Packages/SubusCore` и тестируется `swift test` без Xcode. Таргет `App/` (XcodeGen) — тонкий AppKit/SwiftUI-слой: `NSStatusItem` + панель + окно формы + окно настроек, связанные через `AppModel`. Визуальное направление задаёт impeccable (PRODUCT.md, DESIGN.md) до начала UI-задач.

**Tech Stack:** Swift 6, SwiftUI, AppKit, UserNotifications, ServiceManagement, ImageIO, Foundation `XMLParser`, Swift Testing, XcodeGen, bash.

**Spec:** `docs/superpowers/specs/2026-10-20-subus-v1-design.md`

## Global Constraints

- Минимальная ОС: macOS 14 (`.macOS(.v14)`, deployment target `14.0`); `SWIFT_VERSION 6.0`, swift-tools 6.0. Liquid Glass — только под `if #available(macOS 26, *)`, фолбэк — по DESIGN.md.
- Bundle ID: `io.github.aesarva.Subus`; продукт и исполняемый файл: `Subus`; пакет: `SubusCore`.
- App Sandbox включён; entitlements ровно: `com.apple.security.app-sandbox`, `com.apple.security.network.client`, `com.apple.security.files.user-selected.read-write`. Hardened runtime включён. `LSUIElement = true`.
- Локализация: английский (исходный) + русский, `App/Resources/Localizable.xcstrings`, `String(localized:)`. Все пользовательские строки — только в App; `SubusCore` возвращает данные (числа, даты, enum), а не готовые фразы. Каждая новая строка получает русский перевод в той же задаче.
- Сторонних зависимостей нет. Сеть: только `https://www.cbr.ru/scripts/XML_daily.asp` и сайт подписки по кнопке «Загрузить иконку».
- Деньги — только `Decimal`; в JSON `Decimal` кодируется **строкой** (`"1199.99"`) — это собственный контракт формата файла (не зависит от того, как конкретная версия Foundation декодирует числа); числовой fallback при чтении декодируется прямо в `Decimal`.
- Даты списаний — `LocalDate` (`"YYYY-MM-DD"` в JSON), арифметика — в григорианском календаре UTC внутри `LocalDate`. Календарь приложения для «сегодня», времени напоминаний и начала недели — `Calendar.subus` = `Calendar(identifier: .gregorian)` с `TimeZone.current` и `firstWeekday` из `Locale.current` (никогда не `Calendar.current` напрямую: у пользователя может быть негригорианский календарь).
- Сборка требует Xcode 26+ (Liquid Glass API, формат `.icon`); на машине — Xcode 27.0, XcodeGen 2.46.0.
- Логирование: `os.Logger(subsystem: "io.github.aesarva.Subus", category:)`, категории `store`, `rates`, `reminders`, `logos`, `ui`.
- Все типы ядра — `public`, `Sendable`; всё, что трогает UI, — `@MainActor`.
- Значения по умолчанию: `reminderDays [5, 3, 1]` (допустимо 0…30), время напоминания 10:00, счётчик в строке меню включён, язык — системный, основная валюта — `Locale.current.currency` или `USD`.
- Константы: горизонт планирования 60 дней, бюджет запланированных уведомлений приложения 60 (запас под ограничение системы на число ожидающих локальных уведомлений, ~64), свежесть курсов 24 ч, проверка курсов каждые 12 ч (и при запуске), таймаут ЦБ 10 с; иконки сайта — только https, таймаут 5 с, ≤ 3 редиректов, ≤ 2 МБ, логотип 128×128 PNG.
- Xcode выбирается через `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` в Makefile и скриптах (`xcode-select` не трогаем).
- Git: работа в ветке `feature/v1` от `develop`; коммиты conventional, на английском, в нижнем регистре; каждый коммит заканчивается строками атрибуции из системной инструкции сессии.

## Review Focus

1. **Подписка, начатая много лет назад** (якорь 2015 года, цикл 1 день или месяц с 31-м числом) — `nextCharge` должен вернуть правильную ближайшую дату без перебора тысяч периодов и без «дрейфа» дня месяца. → тест `oldAnchorJumpsDirectly` в Task 4.
2. **Смена валюты при изменении цены** (10 USD → 9 EUR) — «Подорожали за год» не сравнивает суммы в разных валютах, итоги берут новую валюту. → тест `currencyChangeIsNotAnIncrease` в Task 7.
3. **Ввод цены с запятой и пробелами** (`9,99`, `1 199,50` с неразрывным пробелом, `1,199.50`) — форма принимает все привычные варианты в обеих локалях. → тест `parsesLocaleVariants` в Task 13.
4. **Удаление категории или способа оплаты, на которые ссылаются подписки** — ссылки обнуляются, разбивка показывает «Без категории», ничего не падает. → тест `removingCategoryClearsReferences` в Task 3.
5. **Импорт одного и того же файла дважды в режиме «Добавить»** — id подписок, категорий и способов оплаты не должны конфликтовать, у копий — свои файлы логотипов. → тест `importAddingTwiceDoesNotCollideIDs` в Task 11.

Дополнительно по ревью Codex (stage 0) в задачи добавлены тесты на: восстановление после повреждения при двух запусках подряд (Task 11), сбой записи без потери старых данных (Task 11), сохранение догоняющего уведомления при перепланировании (Task 10), переход на летнее/зимнее время (Task 10), инварианты импортированных данных — `cycle_count = 0`, дубли UUID, опасные имена файлов логотипов (Task 3, 11), BOM в CSV (Task 11), редиректы и лимит размера в реальном `URLSessionHTTPClient` (Task 6).

**Сохранение (все мутации):** изменение применяется к **копии** библиотеки → `store.save(copy)`; только при успехе копия публикуется в `library`, `saveError = nil`, затем `replan(justSaved:)`; при ошибке `library` не меняется, `saveError` = локализованное «Couldn't save changes» + описание, метод возвращает `false` (форма остаётся открытой). Логотипы при удалении подписки удаляются только после успешного `save`.
**Перепланирование:** `replan` вызывает `ReminderPlanner.plan(…, calendar: .subus(), justSaved:, carriedCatchUps:)`, где `carriedCatchUps` — догоняющие из предыдущего плана с `fireDate > now` (хранятся в `AppModel`). Календарь везде — `Calendar.subus()`.
**UserNotifier:** тексты уведомлений и категории действий — спецификация §6.1–6.2: категории `SUB_CHARGE_MANAGE`/`SUB_CHARGE` (и `SUB_TRIAL_MANAGE`/`SUB_TRIAL`), действие `MANAGE` открывает `manageURL` через `NSWorkspace.shared.open`; `userInfo["subscriptionID"]`; `willPresent` → `[.banner, .list, .sound]`. Триггеры: обычное — `UNCalendarNotificationTrigger(dateMatching:` компоненты `year, month, day, hour, minute` из `Calendar.subus()` `, repeats: false)`; догоняющее (`isCatchUp`) — `UNTimeIntervalNotificationTrigger(timeInterval: max(1, fireDate − now), repeats: false)`. `replaceAll` снимает только ожидающие запросы, чьи id содержат `|` (наши), ставит новые; ошибки `add` логируются (`reminders`) с id. Без бандла (`Bundle.main.bundleIdentifier == nil`) — no-op. Делегат `UNUserNotificationCenter` устанавливается в `applicationWillFinishLaunching` (до того, как система доставит отклик на холодный запуск по клику); id из отклика до готовности `AppModel` складывается в `pendingOpen` и применяется после загрузки — как `openSubscriptionRequest`. Пути: `FileManager.default.url(for: .applicationSupportDirectory…)/Subus/`, `Logos/`, `rates.json`. `JSONFileStore(initial:)` создаёт `Library.initial(categoryNames:)` с локализованными названиями «Software», «Entertainment», «Music», «Cloud», «Work», «Other». Триггеры `replan()`: запуск, `NSCalendarDayChanged`, `NSWorkspace.didWakeNotification`, изменение настроек. Курсы: при запуске и таймер каждые 12 ч → `refreshRatesIfNeeded()`; ошибки — в лог `rates`. Отладочные аргументы: `-SeedDemoData` (если библиотека пуста — заполнить `demoLibrary`), `-OpenPanelOnLaunch`.
