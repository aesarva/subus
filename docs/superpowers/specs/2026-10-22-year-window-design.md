# Subus: окно «Год»

Дата: 2026-10-22
Статус: черновик на ревью
Основа: v1 (`2026-10-20-subus-v1-design.md`) и `2026-10-21-quick-add-and-colors-design.md`, обе слиты в `develop`.

## 1. Цель

Дать главное окно, в котором виден весь следующий год: сколько и когда спишется, по каким подпискам, с фильтрами. Там же — страница каждой подписки.

**Что сказал пользователь:**

- Нужен отдельный экран в рамках приложения в Dock: все подписки на следующий год, от ежемесячных до ежегодных.
- Красивая визуализация и разнообразные фильтры.
- Страницу подписки можно открыть на отдельном экране.
- Суммы по месяцам, каждая подписка и её списания, детали — всё одинаково важно.
- Визуализация — сетка в духе календаря коммитов: квадрат — неделя или месяц, а его тон зависит от числа списаний в нём. Пять ступеней тона. Недели и месяцы — обе, с переключателем.

**Критерии успеха:**

- За несколько секунд видно, какие недели и месяцы нагружены и чем именно.
- Любую подписку можно найти и открыть её страницу: сколько она стоит за год, когда спишется, как менялась цена.
- Фильтры по категории, карте, периодичности, валюте, пробным и неактивным и поиск меняют сетку, суммы и списки сразу.
- Суммы честные. Это прогноз по расписанию в базовой валюте по текущему курсу ЦБ. Что не удалось пересчитать, названо, а не спрятано.

**Вне объёма:** прошлые списания и журнал оплат, редактирование на самой странице подписки (для этого есть существующий редактор), экспорт года, свой период (только 12 месяцев от сегодня), цветной градиент сетки (тон пока нейтральный; см. 4.2).

## 2. Ядро (SubusCore)

Новые типы — в `Packages/SubusCore/Sources/SubusCore/Presentation/YearPlan.swift`.

### 2.1. Период

Период — от `today` до `today.adding(months: 12).adding(days: -1)` включительно. Например, с 21.10.2026 по 20.10.2027. `adding(months:)` прижимает день к концу месяца, поэтому при `today` = 29.02.2028 период заканчивается 27.02.2029.

Списания берутся из `BillingSchedule.charges(for:in:)`, правила расписания остаются прежними:

- первое платное списание приходится на сам день `trialEndDate`;
- `endDate` включительно;
- подписка завершена, если `endDate < today`;
- цена каждого списания — `price(on: date)` из истории цен.

Даты считаются в календаре `Calendar.subus()`. Он григорианский, часовой пояс и `firstWeekday` берёт из текущей локали.

### 2.2. Фильтр: `YearFilter`

| Поле | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `categoryIDs` | `Set<UUID?>` | пусто = все | `nil` в наборе = «Без категории» |
| `paymentMethodIDs` | `Set<UUID?>` | пусто = все | `nil` = «Без карты» |
| `cycles` | `Set<CycleKind>` | пусто = все | `CycleKind`: `.monthly` (1 месяц), `.yearly` (1 год), `.other` |
| `currencies` | `Set<String>` | пусто = все | по валюте текущей цены `currentPrice(today:)` |
| `includeTrials` | `Bool` | `true` | `false` убирает подписки, у которых пробный период ещё идёт |
| `showInactive` | `Bool` | `false` | влияет только на список «Все подписки» (2.5, 3.3) |
| `query` | `String` | `""` | подстрока в названии, без учёта регистра и диакритики (`localizedStandardContains`) |

Пустой набор означает «без ограничения», а не «ничего». Все условия складываются через «и». Неактивные и завершённые подписки списаний не дают при любом фильтре.

`YearFilter.pruned(to: Library)` убирает из наборов id категорий и карт, которых больше нет в библиотеке. Окно вызывает его при каждом изменении библиотеки. Если категорию удалили, а её чип был выбран, фильтр не превращается в «ничего не найдено».

Пробной считается подписка, у которой `trialEndDate > today`. Это то же правило, что у `SummaryBuilder`, по которому панель пишет «включая N пробных по будущей цене». Все списания такой подписки в периоде помечены `isTrialFuturePrice`. В день `trialEndDate` подписка уже не пробная: в этот день проходит её первое платное списание.

### 2.3. Расчёт: `YearPlan`

```swift
public struct YearPlan {
    public static func build(library: Library, filter: YearFilter, today: LocalDate, calendar: Calendar,
                             baseCurrency: String, converter: CurrencyConverter) -> YearPlan
    public let range: ClosedRange<LocalDate>
    public let charges: [YearCharge]          // по дате, затем по имени, затем по id
    public let weeks: [YearPeriod]
    public let months: [YearPeriod]
    public let total: YearMoney
    public let excludedSubscriptionIDs: [UUID]     // есть списания без курса; по имени
    public let trialSubscriptionIDs: [UUID]
}

/// Сумма по тем списаниям, которые удалось пересчитать, и признак неполноты.
public struct YearMoney { amount: Money; unconvertedCount: Int; convertedCount: Int }

public struct YearCharge { charge: Charge; converted: Money?; isTrialFuturePrice: Bool }

public struct YearPeriod {
    id: LocalDate                // первый день полной недели (или месяца) до обрезки
    start, end: LocalDate        // обрезаны по range
    monthKey: (year, month)      // месяц, к которому относится период
    isPartial: Bool              // обрезан началом или концом range
    charges: [YearCharge]
    count: Int
    total: YearMoney
    level: Int                   // 0...4
}
```

- **Недели.**
  - Неделя начинается с `calendar.firstWeekday`: понедельник для ru, воскресенье для en_US.
  - Неделя относится к месяцу, на который приходится её 4-й день. Для недели с понедельника это четверг, то есть правило ISO. И `id`, и 4-й день считаются от полной недели до обрезки по `range`.
  - Первая неделя содержит `today`, последняя — конец периода.
  - Недель бывает 53 или 54. Например, 02.01.2028–01.01.2029 при `firstWeekday = 2` даёт 54 недели.
  - Столбцов-месяцев бывает 13 или 14, в крайнем столбце может быть всего одна клетка. В столбце от 1 до 5 клеток.
- **Месяцы.**
  - Каждый календарный месяц, который задевает период. Если `today` не 1-е число, их 13: первый и последний неполные (`isPartial`), например «с 21 окт.» и «до 20 окт.».
- **Ступени тона** (`level`) считаются по числу списаний в периоде:
  - неделя: 0, 1, 2, 3, 4 и больше → 0…4;
  - месяц: 0, 1–3, 4–6, 7–9, 10 и больше → 0…4.

  Пороги — константы `YearPlan.weekLevels` и `YearPlan.monthLevels`.
- **Деньги.**
  - Каждое списание пересчитывается в базовую валюту текущим курсом. Это тот же `CurrencyConverter`, что у `SummaryBuilder`.
  - История цен может сменить валюту, поэтому одна подписка может иметь и пересчитанные списания, и непересчитанные.
  - Если курса нет, `converted == nil`. Такое списание входит в `count` и в `unconvertedCount`, но не в `amount`, а подписка попадает в `excludedSubscriptionIDs`.
  - Сумма считается в `Decimal`, без округления до показа.
- **Показ суммы** (одинаково для всего окна):
  - нет списаний — ноль в базовой валюте («0 ₽»);
  - все списания без курса — «—»;
  - часть без курса — сумма и пометка «+ N без курса».

  Исключённые подписки называются по именам, во всплывающей подсказке у пометки «не учтены».
- **Пробные.** Пока пробный период идёт, списаний нет. Списания после него идут по будущей цене и помечены `isTrialFuturePrice`.

### 2.4. Подписка за год: `SubscriptionYear`

```swift
public struct SubscriptionYear {
    public static func build(_ s: Subscription, today: LocalDate, baseCurrency: String,
                             converter: CurrencyConverter) -> SubscriptionYear
    public let charges: [YearCharge]       // все в range
    public let total: YearMoney
    public let next: Charge?               // ближайшее списание от today, даже если за пределами range
    public let firstAtNewPrice: Set<LocalDate>  // даты первых фактических списаний после каждой смены цены в range
}
```

«Новая цена» ставится на первое фактическое списание, у которого цена отличается от предыдущего списания. Сама дата `effectiveFrom` для этого не нужна.

### 2.5. Список «Все подписки»

`YearPlan.subscriptionRows(library:filter:...) -> [YearSubscriptionRow]` возвращает подписки после фильтра. Неактивные и завершённые попадают в список, только если включён `showInactive`. Каждая строка содержит сумму за год (`SubscriptionYear.total`), число списаний и ближайшую дату (`next`, может быть и за пределами года).

Сортировки:
- по сумме за год (по умолчанию, по убыванию; «—» в конце);
- по ближайшей дате (без даты в конце);
- по имени (`localizedStandardCompare`).

При равенстве порядок решает имя, а затем id.

## 3. Интерфейс (App)

Файлы — в `App/Year/`: `YearWindowController.swift`, `YearView.swift`, `YearGrid.swift`, `YearSidePane.swift`, `SubscriptionPage.swift`, `YearToolbar.swift`.

### 3.1. Окно

- **Одно окно** «Год» (`NSWindow` с `NSHostingController`), `window.identifier = DockPresence.identifier`. Пока окно открыто, иконка видна в Dock и в ⌘Tab.
- **Размер.** По умолчанию 1100 × 720 pt, минимум 960 × 600. Размер и положение запоминаются через `setFrameAutosaveName("YearWindow")`.
- **Как открыть:**
  - кнопка «Год» (`calendar`) в подвале панели между «Добавить» и счётчиком;
  - пункт «Год» в быстром меню;
  - клик по иконке в Dock: `applicationShouldHandleReopen` открывает «Год», если не открыто другое окно;
  - пункт меню «Окно → Год», ⌘Y.
- **Состояние.** Режим «Недели / Месяцы» запоминается в `UserDefaults` (`yearMode`). Фильтры и выбранная клетка живут, пока окно открыто.
- **Пересчёт.** План собирается заново, когда меняется что-то из этого:
  - библиотека или настройки в `AppModel`;
  - день: те же уведомления, что у панели (смена дня, часового пояса, пробуждение);
  - локаль: `NSLocale.currentLocaleDidChangeNotification`, от неё зависит `firstWeekday`.
- **Выбор при пересчёте и смене режима.**
  - Выбранная клетка запоминается по дате начала.
  - При переключении «Недели → Месяцы» выбирается месяц, в котором лежит эта дата.
  - При переключении «Месяцы → Недели» выбирается текущая неделя, если месяц текущий, иначе первая неделя месяца.
  - Если после пересчёта выбранной даты в периоде больше нет, выбирается текущая неделя или месяц.

### 3.2. Панель инструментов

Стандартный `.toolbar` SwiftUI. На macOS 26 он стеклянный сам, на 14–15 это unified toolbar. Слева направо:

1. Заголовок «Год» и подзаголовок с периодом («21 окт. 2026 — 20 окт. 2027»).
2. `Picker(.segmented)`: «Недели» / «Месяцы».
3. Чипы категорий: «Все», по одному на каждую категорию, у которой есть подписки, и «Без категории», если есть подписки без неё. Чип — переключатель с кольцом цвета категории (`StationRing`; у «Без категории» кольцо цвета рельса). Выбор нескольких допускается, «Все» сбрасывает выбор.
4. Меню «Фильтры» с отметкой числа активных условий:
   - карты (несколько, включая «Без карты»);
   - периодичность;
   - валюта;
   - «Пробные по будущей цене» (вкл.);
   - «Показывать неактивные» (выкл.);
   - «Сбросить фильтры».
5. Поле поиска (`.searchable`).

Чипы — один `ToolbarItem` со своим адаптивным содержимым (`ViewThatFits`), на системный overflow мы не полагаемся. Варианты перебираются по порядку, берётся первый, который помещается:

1. все чипы;
2. первые чипы и меню «Ещё» с остальными (отметка у выбранных);
3. одно меню «Категории» с отметками.

### 3.3. Основная область

Сверху вниз и слева направо:

- **Сводка.**
  - «Спишется за 12 месяцев» и сумма 28 pt.
  - Под ней caption: «N списаний · ≈ X в месяц · курс ЦБ на дату», а при пробных — «включая N пробных по будущей цене».
  - Если у части подписок нет курса — «не учтены N подписок (нет курса)».
  - Подпись намеренно отличается от панельного «… в год». Там нормированная стоимость, здесь прогноз по расписанию.
- **Сетка (слева, в карточке).**
  - Режим «Недели»: столбцы — месяцы (по `monthKey`), строки — недели месяца сверху вниз, от 1 до 5 клеток в столбце, 13 или 14 столбцов (2.3). Над столбцами подписи месяцев, у января другого года — « ’27».
  - Режим «Месяцы»: плитки в 4 столбца. Внутри плитки подпись месяца, число списаний (26 pt) с подписью «списаний» и сумма. У неполных месяцев — «с 21» или «до 20».
  - Клетка недели — квадрат 36–56 pt (растёт с окном), скругление 7 pt, интервал 6 pt.
  - Тон клетки — ступень 0–4 (4.2).
  - Обводки идут снаружи клетки, через зазор цвета фона карточки. Поэтому их контраст считается к фону, а не к тону клетки: на ступени 2 оранжевый дал бы всего 1.4:1.
    - Текущая неделя или месяц: зазор 1.5 pt и кольцо 2.5 pt цвета `accent` (#E8590C, «сейчас»; 3.3:1 к светлому фону, 4.75:1 к тёмному).
    - Выбранная клетка: зазор 2 pt и кольцо 2 pt цветом `labelColor`.
    - Клетка, которая одновременно текущая и выбранная: оранжевое кольцо, а за ним ещё зазор 1.5 pt и кольцо `labelColor` 1.5 pt.
  - Под сеткой легенда: «меньше списаний», пять образцов, «больше» и пороги текущего режима («0 · 1 · 2 · 3 · 4+» или «1–3 · 4–6 · 7–9 · 10+»).
  - Управление:
    - клик выбирает клетку;
    - стрелки двигают выбор по сетке, Return открывает первую подписку клетки;
    - наведение показывает подсказку «8–14 февраля · 2 списания · 8 233 ₽».
- **Правая панель** (минимум 320 pt). Сверху `Picker(.segmented)`: «Неделя» (или «Месяц», по режиму) и «Все подписки».
  - **Выбранная клетка.**
    - Заголовок 20 pt («8–14 февраля» или «Февраль 2027»), под ним «N списаний · сумма».
    - Строки по дате: логотип 28 pt, название, «кольцо категории · дата, день недели · карта», справа сумма в валюте и «≈ в базовой валюте» (если валюта другая). Годовые помечены «раз в год», пробные — тегом Trial.
    - При открытии окна выбрана текущая неделя или месяц.
  - **Все подписки.**
    - Строки: логотип, название, «цена / период · категория», справа сумма за год и «следующее — дата».
    - Над списком меню сортировки.
    - Неактивные (при `showInactive`) — с тегом «Неактивна» или «Завершена», текст не тускнеет.
  - Клик по строке в любом режиме открывает страницу подписки (3.5).

### 3.4. Пустые и особые состояния

- **Данные не прочитаны или не сохранены** (`AppModel.saveError` или `recovery`). Сверху окна стоит тот же баннер, что в панели (`PanelBanner`), с теми же действиями. При ошибке чтения библиотека временно пуста (`.empty`), но это не выдаётся за новую библиотеку: состояние «Вы здесь» не показывается, вместо него сообщение баннера.
- **Нет подписок совсем.** Состояние «Вы здесь» из DESIGN.md с кнопкой «Добавить подписку» (открывает редактор).
- **Фильтр ничего не нашёл.** Ни одна подписка не прошла фильтр. На месте сетки «Ничего не найдено» и кнопка «Сбросить фильтры». Сетку не рисуем.
- **Подписки есть, а списаний за год нет.** Например, все неактивны, первое списание через год с лишним или пробный период дольше года. Сетка рисуется пустой, над ней строка «В ближайшие 12 месяцев списаний нет». Правая панель сама переключается на «Все подписки», и в ней виден каждый вариант с его ближайшей датой.
- **Пустая клетка.** «В эту неделю списаний нет» (или «В этом месяце»), под этим ближайшее списание после неё.
- **Нет курса.** В подсказке клетки «+ N без курса», в списке строка без «≈», сумма клетки без них.

### 3.5. Страница подписки

Открывается в том же окне (`NavigationStack`, путь из `UUID`). Вернуться можно кнопкой «‹ Год» в панели инструментов, клавишей Esc или ⌘[. Выбор клетки и прокрутка при возврате сохраняются.

- **Шапка.**
  - Логотип 56 pt, название 22 pt semibold, теги Trial / «Неактивна» / «Завершена».
  - Строка цены: «$28.90 в месяц», для других периодичностей ещё «≈ X в месяц».
  - Запланированная смена цены: «→ 399 ₽ с 12 янв.».
  - Справа кнопки «Изменить» (редактор этой подписки) и «Управлять подпиской ↗» (если есть `manageURL`).
- **«За 12 месяцев».**
  - Сумма и число списаний.
  - Сетка недель (как в 3.3) этой одной подписки. Клетки без списаний — ступени 0. В клетке со списанием станция категории 13 pt: её линия (`LinePalette.line`) на заливке цвета фона карточки с ореолом 1 pt того же цвета. Контраст станции к фону — тот же, что гарантирует `LineContrast`.
  - Клик по клетке выделяет строку в «Списаниях».
- **«Списания».** Все даты периода: дата и день недели, сумма в валюте, «≈ в базовой валюте». Ближайшая помечена «следующее», первое фактическое списание по новой цене — «новая цена» (2.4).
- **«История цен».** Только если записей больше одной: «старая → новая · с даты · +N %». Проценты считаются, только если валюта у обеих цен одна и старая цена больше нуля. Иначе просто «старая → новая · с даты». Рост от 10 % — accent text, как в панели.
- **«Детали».**
  - Категория (кольцо и название), карта, периодичность, первое списание, конец пробного периода, дата окончания, сайт ссылкой.
  - Заметки полностью, с выделяемым текстом.
- **Неактивная или завершённая.** Вместо сетки — «Списаний в ближайший год нет». История и детали остаются.
- **Подписку изменили или удалили, пока страница открыта.** Страница пересчитывается из `AppModel`. После удаления окно возвращается к году.

### 3.6. Доступность и локализация

- **VoiceOver.**
  - Сетка — контейнер с подписью «Год по неделям». Каждая клетка читается как «Неделя 8–14 февраля: 2 списания, 8 233 ₽» и отмечает, если неделя текущая.
  - Тон не единственный носитель смысла: число есть в подписи, подсказке и правой панели.
- **Клавиатура.** Сетка, правая панель и страница работают с клавиатуры (Tab, стрелки, Return, Esc).
- **Increase Contrast.** У клеток 1 pt контур `separatorColor`, ступени берутся из отдельной шкалы (4.2).
- **Reduce Motion.** Переход на страницу подписки без анимации.
- **Строки.** Все новые строки — в `Localizable.xcstrings` (en — источник, ru — перевод). Склонения («1 списание», «2 списания», «5 списаний») — через plural-варианты.

## 4. Дизайн-система

### 4.1. Мир

Окно продолжает мир «Линия» из DESIGN.md: SF Pro, табличные цифры, кольца-станции в цвете категории, один оранжевый для «сейчас», семантические цвета текста.

Это первое большое окно, поэтому в нём есть то, чего нет в панели. В DESIGN.md это будет описано отдельным разделом «Окно „Год“». Правила панели («без карточек», «одно большое число», «полные чернила только у сегодня, отрезка и подписи станции») для панели не меняются.

Отступления в окне:

- **Карточки.** Две поверхности: сетка и плитки месяцев, с радиусом 16 и 14 pt на `windowBackgroundColor`.
- **Крупные числа.** Сумма в сводке (28 pt) и числа в плитках месяцев (26 pt). Число дней в панели остаётся единственным крупным числом в панели.
- **Полный цвет текста на графике.** Ступень 4 сетки и кольцо выбора. Это шкала количества, а не акцент «сейчас».

### 4.2. Ступени тона сетки

Нейтральная шкала, потому что цвет линии означает только категорию, а оранжевый — «сейчас».

| Ступень | Светлая | Тёмная | Светлая, Increase Contrast | Тёмная, Increase Contrast |
|---|---|---|---|---|
| 0 | #E8E8E4 | #2C2C2E | #DADAD4 | #3A3A3C |
| 1 | #CFCFCA | #48484A | #B3B3AD | #5A5A5E |
| 2 | #A3A39D | #6E6E73 | #808079 | #8E8E93 |
| 3 | #5E5E5A | #A1A1A6 | #45453F | #C7C7CC |
| 4 | #1D1D1F | #F2F2F0 | #000000 | #FFFFFF |

Цвет текста на плитках месяцев задан для каждой ступени отдельно, «инверсия от ступени 3» не годится для всех шкал:

- светлая: ступени 0–2 — #1D1D1F, ступени 3–4 — #FFFFFF;
- тёмная: ступени 0–2 — #F2F2F0, ступени 3–4 — #1C1C1E;
- светлая с Increase Contrast: ступени 0–2 — #000000, ступени 3–4 — #FFFFFF;
- тёмная с Increase Contrast: ступени 0–1 — #FFFFFF, ступени 2–4 — #000000.

Тест проверяет все 20 пар «ступень/текст» через `LineContrast.ratio`: не ниже 4.5:1. Самая слабая пара сейчас — 4.52:1, тёмная шкала, ступень 2. Он же проверяет графику: оранжевое кольцо и кольцо выбора к фону карточки должны давать не ниже 3:1.

Фон карточки: #FBFBF9 в светлой теме, #232325 в тёмной.

### 4.3. Направление

Процесс impeccable: shape → выбор композиции (в два круга и по прямому выбору пользователя) → «сетка недель с переключателем на месяцы». Эскизы лежат в `.impeccable/mocks/decision/count-weeks.html` и `count-months.html`.

Перед сборкой контракт направления записывается в surface brief `App/Year/YearView.swift`. После сборки обязательны finish review и обновление DESIGN.md и `.impeccable/design.json` через documenter.

## 5. Тестирование

**Ядро** (`YearPlanTests.swift`, `SubscriptionYearTests.swift`):

- **Период.** 21.10.2026 → 20.10.2027 включительно. Списание ровно на последний день входит, на следующий день — нет. Старт 29.02.2028 даёт конец 27.02.2029.
- **Границы расписания.**
  - Пробная подписка с `trialEndDate` = сегодня + 3: до этой даты списаний нет, в сам день — первое.
  - `endDate` включительно.
  - Подписка с `endDate < today` завершена.
  - Подписка, у которой первое списание за пределами года, даёт 0 списаний и `next` за пределами периода.
- **54 недели.** Период 02.01.2028–01.01.2029 при `firstWeekday = 2` даёт 54 недели и 14 месячных столбцов. Крайние столбцы — по одной клетке.
- **Недели.**
  - Правило 4-го дня:
    - неделя 28.12.2026–03.01.2027 (четверг 31.12) относится к декабрю;
    - неделя 29.03–04.04.2027 (четверг 01.04) относится к апрелю;
    - неделя 30.11–06.12.2026 (четверг 03.12) относится к декабрю.
  - `firstWeekday = 1` (воскресенье) даёт другие границы.
  - Первая неделя содержит `today`.
- **Месяцы.** 13 периодов при `today` не 1-го числа и 12 при 1-м. Неполные помечены, границы обрезаны.
- **Ступени.** Пограничные значения для недель (0, 1, 3, 4, 7) и месяцев (0, 1, 3, 4, 6, 7, 9, 10).
- **Фильтры.** Каждое поле отдельно, пустой набор = все, `nil` = «без категории/карты», сочетание условий, поиск без учёта регистра и «ё/е» по `localizedStandardContains`.
- **Пробные.** До конца пробного периода списаний нет. Первое после — по будущей цене и с пометкой. `includeTrials = false` убирает такую подписку.
- **Неактивные и завершённые.** Не дают списаний. В «Все подписки» попадают только с `showInactive`.
- **Деньги.**
  - Сумма по клеткам равна `total.amount`.
  - Неконвертируемая валюта входит в `count` и `unconvertedCount`, но не в `amount`, и названа в `excludedSubscriptionIDs`.
  - Подписка со сменой валюты в истории даёт часть пересчитанных списаний и часть нет.
  - Показ: «0 ₽», «—», «сумма + N без курса».
- **Фильтр валюты** смотрит на текущую цену, а не на последнюю запланированную.
- **`pruned(to:)`** убирает удалённые категорию и карту из фильтра.
- **Смена цены внутри периода.** Суммы до и после даты разные. `firstAtNewPrice` — дата первого фактического списания по новой цене.
- **Сортировки «Все подписки».** «—» и подписки без даты идут последними, при равенстве решает имя, затем id.
- **История цен.** Проценты есть только при одной валюте и старой цене больше нуля.
- **Контраст.** 20 пар «ступень/текст» не ниже 4.5:1, кольца «сейчас» и выбора к фону карточки не ниже 3:1.
- **Високосный год.** Период через 29.02.2028 (при `today` = 01.03.2027) и ежемесячная подписка на 31-е число.

## 6. Совместимость и риски

- Формат данных не меняется, схема остаётся версии 1. Новые настройки — только `UserDefaults` (`yearMode`).
- PRODUCT.md меняется: у приложения появляется главное окно «Год», а фраза «No main window» уходит.
- **Риск: однотонная месячная сетка.** Если почти всё ежемесячное, у всех месяцев одна ступень. Разницу дают годовые подписки и режим недель, поэтому недели — режим по умолчанию.
- **Риск: тон показывает число, а не сумму.** Дорогая годовая неделя может быть светлой. Сумма всегда видна в подсказке, в правой панели и в плитке месяца. Режим «по сумме» оставлен на будущее.
- **Риск: много подписок.** При 50+ подписках неделя может набрать 10+ списаний. Ступень 4 означает «4 и больше», а точное число есть в подсказке и правой панели.
